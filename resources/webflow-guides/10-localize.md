# Webflow Localize — resource notes (2026-10-11)

Source: https://webflow.com/feature/localize

## Core idea
Multi-locale versions of the site: translate content, customize imagery per
region, keep SEO correct per locale — all visual, no code.

## Key features
- **Translation**: native AI-powered first pass (incl. agentic auto-translation
  of new/changed content), manual refinement, custom glossaries.
- **TMS integrations**: Smartling, Lokalise, Phrase, Crowdin, Transperfect via
  Webflow Apps or APIs.
- **Per-locale customization**: different images, alt text, styles, even
  show/hide elements per locale.
- **SEO handled**: hreflang tags, localized sitemaps, locale subdirectories
  (e.g. /es/), localized meta titles/descriptions/OpenGraph, HTML lang tags.
- **Locale switcher** element for visitors; auto-routing by browser settings
  (Enterprise/Advanced plans).

## Pricing note
Localize is its own add-on: try free, pay when publishing localized content.
