# Webflow SEO — resource notes (2026-10-11)

Source: https://webflow.com/feature/seo

## Core idea
Built-in SEO + AEO controls, no plugins needed.

## What's included
- **Meta titles/descriptions**: per-page editing, or auto-generated from CMS
  fields (define a pattern once, every Collection page follows it).
- **AI assists**: Webflow AI fills missing metadata, generates schema markup,
  generates alt text (one-off or bulk), sitewide SEO/AEO audits with an
  "AEO maturity score" and prioritized fixes.
- **Technical SEO**: clean semantic HTML auto-generated, SSL included,
  XML sitemap auto-generated, robots.txt controls, page URL control,
  301 redirect management (bulk on higher plans).
- **Schema markup**: generate/edit structured data so content is discoverable
  across search and AI-powered experiences.
- **AEO angle**: structured content + semantic markup helps AI systems surface
  the content in answers and featured snippets; topic clusters and clear
  information architecture recommended.
- **Performance**: global hosting (100+ data centers), fast loads — a ranking
  factor. Real-time SEO tips + audit logs while designing.

## Why it matters for the-manik-cryptid build
- Every book/story page gets proper meta from the CMS automatically.
- Alt text on all the Forest artwork (accessibility + discovery).
- Schema markup for books (Book schema = rich results on Google).
- This + the seo-checklist.md already filed = the full SEO game plan.
