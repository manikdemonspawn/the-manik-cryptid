# Webflow Analyze — resource notes (2026-10-11)

Source: https://webflow.com/feature/analyze

## Core idea
Native analytics inside Webflow — no Google Analytics required (though you can
still add it).

## What's included
- **One-click setup**: events captured automatically once enabled.
- **Metrics**: sessions, unique visitors, page views, bounce rates, click
  events, traffic by device/language/location/referrer, page-level flow and
  goal conversion.
- **Visual analytics**: clickmaps and scrollmaps overlaid on the actual page
  designs; "Analyze Mode" shows live insights while editing.
- **Privacy**: cookie-less tracking, no session recordings (lighter, cheaper,
  fewer privacy risks), automatic bot filtering, no-code goal tracking.
- **AEO analytics** (Enterprise add-on only): how AI systems cite the brand —
  visibility score, citation rate, which AI bots crawl the site, AI-referred
  visitor behavior.

## Why it matters for the-manik-cryptid build
- Day one: turn it on, see which pages/stories get read, where visitors drop.
- Clickmaps show whether anyone actually clicks the book-buy buttons.
- AEO analytics = Enterprise-only; skip. The core analytics are enough.
