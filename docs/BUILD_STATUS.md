# Construction Build Status

## Built before final visual targets

- Public `main` branch intentionally contains no site HTML.
- Active work lives on `construction`.
- Nexus is wired as the central fairy-forest threshold.
- Seven active realm entrances are linked.
- Nexus includes an image-ready hotspot layer independent of final artwork.
- Museum hierarchy supports ceremonial, hearth-scale, and ordinary exhibits.
- Library decontamination is an interactive sequence rather than a decorative link.
- Main Library has district structure for writing, audio/soundscapes, apps, art/multimedia, platform gateways, resurrected holdings, and special collections.
- Hidden bookcase reveal and black-door sequence are wired.
- Forbidden Library contains only safe structural placeholders. Real adult access remains blocked pending real age assurance.
- Morgue structure supports dead and resurrected records, toe-tag metadata, and ghost presentation.
- Crypt, Guild Hall, Curio Shop, Apothecary, Yard Sale, and Catacombs have independent expandable structures.
- Affiliate disclosure appears before yard-sale content.
- Posthumous Mausoleum is documented but not exposed in live navigation.
- `noindex` metadata and `robots.txt` block indexing on the construction build.
- Reduced-motion behavior exists for animated placeholders.
- An accessible Realm Index provides non-visual fallback navigation.
- Artifact schema, canonical artifact registry, reusable artifact renderer, page templates, and realm manifest exist.
- Final-art CSS hooks and asset naming contract exist.
- Approved visual targets are documented as lore-bearing artifacts rather than disposable mockups.

## Things that should NOT be guessed in code

These remain intentionally unfilled until verified or supplied:

- Cherokee writing, Blackfoot writing, and culture-specific inscriptions or symbols;
- Elder Futhark transliterations and their final English wording;
- actual adult/restricted content;
- a real age-verification / age-assurance provider;
- store/payment providers and final affiliate links;
- app-store URLs, Spotify/YouTube/Patreon links, and other external destinations;
- final domain and production analytics/privacy configuration;
- final fonts that require outside font licensing or hosting decisions;
- final art assets.

## Practical code ceiling before art

The structural build can continue to receive real content and verified service integrations later, but the remaining major visual decisions now belong to the approved visual-target phase. Final art should be created to the specifications in `docs/ART_ASSET_CONTRACT.md` and then integrated without changing realm architecture.
