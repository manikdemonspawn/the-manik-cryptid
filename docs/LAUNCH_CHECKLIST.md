# Launch Checklist

Do not merge the construction branch into `main` merely because the pages render.

## Must be finished before public launch

- [ ] Creator explicitly approves public launch.
- [ ] Final Nexus visual target approved and integrated.
- [ ] Realm visual targets approved and integrated.
- [ ] Final realm display fonts chosen and tested.
- [ ] Handwriting-style body font remains readable on mobile and at browser zoom.
- [ ] Every active realm threshold has a keyboard-accessible and screen-reader-accessible link.
- [ ] All links pass an internal audit.
- [ ] Mobile layouts checked on narrow screens.
- [ ] Reduced-motion behavior checked.
- [ ] Image alt text written from actual final imagery.
- [ ] Cultural inscriptions verified before publication.
- [ ] Cherokee and Blackfoot material remains separate and accurately attributed.
- [ ] Elder Futhark transliterations checked before visible final use.
- [ ] Affiliate disclosure final wording reviewed and remains immediately visible on yard-sale entry.
- [ ] Product/affiliate distinction remains clear.
- [ ] Any health-adjacent Apothecary copy avoids unsupported medical-treatment claims.
- [ ] External-platform links point to the correct creator-controlled destinations.
- [ ] Restricted content remains absent until real age assurance exists.
- [ ] Forbidden Library direct URLs/assets are actually protected, not merely hidden behind JavaScript theater.
- [ ] Mature-content advisories defined before restricted works are loaded.
- [ ] Public search indexing intentionally enabled only when ready.
- [ ] `robots.txt` / meta robots settings updated for launch.
- [ ] Custom domain decision made only when the site is ready for a real audience.

## Posthumous Mausoleum lock

- [ ] No active Mausoleum portal exists during creator's lifetime.
- [ ] Activation process is documented separately before launch if desired.
- [ ] Personal/private material receives its own release rules rather than being dumped wholesale into the future Mausoleum.

## Nice-to-have after launch

- [ ] Realm-specific ambient sound controls, opt-in and never autoplayed at punishing volume.
- [ ] Search / artifact index once collections are large enough to need it.
- [ ] Filter deceased / resurrected Morgue records.
- [ ] Filter Library artifacts by medium / platform.
- [ ] Museum timeline / lineage navigation if the collection becomes large.
- [ ] Analytics chosen with privacy in mind.
