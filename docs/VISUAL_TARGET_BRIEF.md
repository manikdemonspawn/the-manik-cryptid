# Visual Target Brief — Generate Only After Code Ceiling

This file records what the eventual generated visual targets need to solve. The visual targets are not the website architecture; they are the art-direction reference for the already-built structure.

## Global target

Create one very large full-Nexus composition showing the fairy forest and all active realm thresholds in a coherent impossible landscape.

The Nexus image must include:

- unmistakable Manik Cryptid visual language;
- mushrooms;
- skulls and strange hanging curiosities in trees;
- carved tree trunks;
- old paths, roots, mist, and forest depth;
- distinct cultural-influence zones rather than one blended folklore aesthetic;
- active realm thresholds placed clearly enough to become website interaction targets;
- NO active Mausoleum portal in the living-site visual.

The Nexus should feel explorable rather than like a menu pasted on a forest wallpaper.

## Realm visual targets

### Museum

- enormous Stonehenge threshold in the Fae / Irish-Scottish influenced forest zone;
- crossing the threshold leads to a real museum interior rather than a Stonehenge-themed museum;
- monumental gallery architecture;
- gigantic ceremonial certificate frames;
- wall-dominating hearth-scale photographs / core artifacts;
- ordinary exhibit cases for normal-important items.

### Library

- sealed decontamination / preservation threshold;
- after passing through: immense Vatican-archive scale;
- old-world stone, wood, balconies, galleries, enormous ceilings, controlled light, corridors disappearing beyond sight;
- districts for writing, listening, interactive apps, art, multimedia, and special collections;
- resurrected artifacts can wander like zombies;
- secret bookcase should visually belong to the Library rather than advertise itself.

### Forbidden Library

- hidden bookcase opened;
- severe black door behind it;
- `ABANDON ALL HOPE, YE WHO ENTER HERE.` carved into the door itself;
- access checkpoint before restricted collections;
- mature archive rather than porn-store aesthetic;
- erotica shelf is deep oxblood / wine / dark crimson;
- other restricted shelves clearly differ from erotica.

### Morgue

- clinical institutional morgue doors;
- gurneys and stainless-steel cold storage;
- toe tags are a major information motif;
- resurrected artifacts float like ghosts with death/resurrection tags still attached;
- Norse death-memory influence can appear around or near the realm without turning the clinical Morgue into a Viking theme park.

### Krypt

- coffin / sarcophagus threshold;
- protected vault of memory, guarded truth, honored dead, afterlife belief threads, and restricted/offline-only records;
- stone, burial, guarded archive, sealed indexes, and protected record symbolism;
- Norse / Elder Futhark layer with room for translations;
- ravens / afterlife atmosphere where appropriate;
- visually distinct from the clinical Morgue.

### Guildhall

- castle door threshold, unequivocal;
- medieval / guild architecture;
- banners, worktables, records, skill displays;
- should feel like capabilities are practiced here, not like a résumé exhibit.

### Kurio Shop

- round storybook door incorporated into a crooked storefront;
- cozy/weird shop interior;
- main floor for Cryptid-made goods;
- visible upstairs stair route to the Apothecary with a rope at the bottom marked `UNDER KONSTRUCTION`;
- visible back door toward Yard Sale;
- not direct Tolkien imitation.

### Forge

- confirmed top-level realm portal;
- visibly marked `UNDER KONSTRUCTION`;
- final purpose, threshold, visual language, and content are deliberately deferred;
- do not invent symbolic details merely to fill the visual target.

### Apothecary

- upstairs room physically inside the Kurio Shop;
- rope at the bottom of the stairs marked `UNDER KONSTRUCTION`;
- jars, drawers, herbs, handwritten labels, reference books, old wood, glass, honey / botanical details;
- voice feels personal to The Manik Cryptid rather than generic universe narration;
- digital guides should appear as tactile in-world objects / shelf cards.

### Affiliate Yard Sale

- clearly outside behind the Kurio Shop;
- huge hand-painted affiliate-disclosure banner visible immediately on exit;
- folding tables, crates, fence, lanterns, weird finds;
- more lawless / informal than the main shop;
- still unmistakably part of the same universe.

### Katakombs

- cellar-door portal at the bottom of the Nexus;
- legalese-only infrastructure realm: policies, permissions, administration, and site machinery;
- physical downward descent;
- roots transition into stone;
- tunnels, iron gates, low light, depth;
- should feel underneath the universe.

## Cultural visual notes

### Irish / Scottish Fae zone

Strongest around the Stonehenge / Museum region. Use verified/traditional-inspired carving language carefully rather than fake "Celtic-looking" gibberish.

### Cherokee / Blackfoot / living-apothecary zone

- keep Cherokee and Blackfoot elements distinct from each other;
- do not generate fake text or pseudo-glyphs;
- use verified writing only when researched;
- one medium-to-large dreamcatcher may exist as a personal-practice element, not as a claim that it is Cherokee or Blackfoot;
- living herbs, rue, ginger, thyme, honey, bees / hive imagery can be part of the environment.

### Norse zone

- strongest around Morgue / Krypt region;
- Elder Futhark text must be verified separately before it becomes legible final signage;
- death, memory, ancestry, runestone, raven atmosphere;
- no extremist/political iconography.

## Art-production rule

Generated targets should prioritize composition, architecture, atmosphere, object placement, and realm identity. Any visible culturally specific text that cannot be guaranteed correct should be left blank / abstract in the image and overlaid later as verified HTML/CSS text.
