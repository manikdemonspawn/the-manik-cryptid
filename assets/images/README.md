# Visual Asset Staging Area

Approved visual targets belong under this directory after the code-first build reaches its practical ceiling.

Planned structure:

```text
assets/images/
├── nexus/
├── portals/
└── realms/
    ├── museum/
    ├── library/
    ├── forbidden-library/
    ├── morgue/
    ├── crypt/
    ├── guild-hall/
    ├── curio-shop/
    ├── apothecary/
    ├── yard-sale/
    └── catacombs/
```

Do not delete an approved earlier visual simply because a newer version exists. Approved development visuals become lore-bearing artifacts and should be archived with versioned filenames when superseded.
